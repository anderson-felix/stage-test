# Glossário

> Revisado em: 26/10/2026

Os mesmos termos do Stage Hub.

| Termo | O que significa aqui | Evitar |
|---|---|---|
| Hub | O Stage Hub, app web onde o time de marketing opera | |
| Pauta | Um tema com ângulo definido, que dá origem a um ou mais Posts (um por Canal) | Tema solto, ideia |
| Post | Uma publicação planejada para um Canal, com formato, Roteiro, Legenda, Arte e data planejada | Conteúdo, peça |
| Canal | Onde o Post sai: Instagram ou LinkedIn | Rede, plataforma |
| Roteiro | O texto final de cada slide do Post, com a indicação visual | |
| Legenda | O texto que acompanha o Post no Canal | |
| Arte | As imagens do Post (HTML renderizado em PNG pelo hub, ou feita pelo designer) | |
| Série | A família visual e editorial do Post: cultura-em-acao, dado, na-midia, socios, evento, conteudo | |
| Campanha | Um conjunto de anúncios de Google Ads para um serviço, com pesquisa, grupos e LP | |
| LP | Landing page de um serviço, com formulário de interesse | |
| Cérebro da Stage | Como este workspace é apresentado fora do time técnico: contexto, marca e skills | |
