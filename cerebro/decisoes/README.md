# Decisões

Uma decisão por arquivo: `AAAA-MM-DD-assunto.md`. Cada uma diz o que foi decidido, por quê, quem
decidiu e o que muda na prática. Decisão substituída não é apagada: a nova aponta para ela.

## Modelo

```markdown
# [Assunto] — DD/MM/AAAA

- **Decidiu:** [nome]
- **Situação:** valendo · substituída por [arquivo]

## O que foi decidido
## Por quê
## O que muda na prática
## Alternativas descartadas
```
