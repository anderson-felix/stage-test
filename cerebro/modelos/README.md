# Modelos

Material de apoio do `/instalar` e de quem está configurando o TatuOS.

- `perfis/`: como o TatuOS se ajusta a cada tipo de negócio (empresa com time, agência ou
  consultoria, freelancer, negócio de uma pessoa só). O `/instalar` lê o perfil escolhido.
- `marca/`: guias visuais de exemplo, fictícios, para mostrar como um `marca/guia-visual.md`
  preenchido fica.
