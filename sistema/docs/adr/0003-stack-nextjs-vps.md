# Next.js + TypeScript + Tailwind, deploy futuro em VPS própria com Docker

O hub é um app Next.js (TS + Tailwind) pensado para rodar numa VPS própria com Docker, não em serverless. O Claude Code headless precisa de processo longo, sistema de arquivos com o workspace e binário local, o que não cabe em funções serverless. Persistência futura em Postgres/Supabase quando o hub virar multiusuário (~10 pessoas).
